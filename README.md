# Galaxy Curve Lab

A local viewer for your own radial measurements. Open `index.html` in a browser and choose a CSV file. Nothing needs to be installed.

Use a header row and select the radius and measured-value columns. Optional columns identify objects, give symmetric measurement uncertainties, or supply a curve you have already calculated in the same units. Rows without a numeric radius or measurement are counted and omitted. The data table and SVG export use the selected object.

No datasets, equations, fitting routines or reference models are included. Files are read in the browser and are not uploaded or saved by the app. Closing or reloading the page clears the session.
